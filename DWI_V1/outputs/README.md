# DWI_V1 outputs

Use this tree for curated, cross-experiment deliverables:

- `analysis/` — comparison tables and final analyses;
- `metrics/` — compact CSV/JSON metrics;
- `reports/` — human-readable reports;
- `presentations/` — selected presentation deliverables;
- `models/`, `predictions/`, `figures/`, `inference/`, `log_archive/` — local
  generated artifacts ignored by Git.

Raw per-run products should stay with their experiment rather than being copied
here unless they form a curated final deliverable.
